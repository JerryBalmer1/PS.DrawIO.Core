# Composition signals

Append-only log of evidence that multi-provider graph composition is needed,
where it should live, or what the contract still lacks.

Format per entry:

```
### S-NNN — YYYY-MM-DD — <short title>
**Source:** where the signal came from (spike, provider, review, …)
**Observation:** what was seen
**Implication:** what it suggests about composition ownership or contract shape
```

No entries yet. Empty is meaningful: composition ownership remains undecided
(see Registry ADR 0003 Decision 5; Core ADR 0001).
